# unslop-ko

한국어 글에서 AI가 쓴 티를 지우는 Claude 플러그인이다. 뜻은 그대로 두고, AI 글에 따라붙는 기호와 문장 틀만 고친다.

## 들어 있는 것

| 종류 | 이름 | 하는 일 |
| --- | --- | --- |
| 스킬 | unslop-ko | 지휘한다. 기호를 세어 길을 고르고, 에이전트를 부르고, 어긋난 줄을 되돌리고, 결과를 낸다 |
| 에이전트 | unslop-diagnostician | 진단한다. 양식으로 둘 곳, 뜻 잠금 항목, 고칠 곳을 적은 진단서를 낸다. 고치지 않는다 |
| 에이전트 | unslop-rewriter | 윤문한다. 진단서에 적힌 곳만 고친다 |
| 에이전트 | unslop-checker | 점검한다. 원문과 고친 글만 받아 직접 대조한다. 다시 쓰지 않는다 |
| 스크립트 | scripts/unslop_check.py | 기호를 세고, 원문과 고친 글의 숫자를 대조한다 |

## 설치

Claude Code에서 아래 두 줄을 차례로 입력한다.

```
/plugin marketplace add ProblmZro/unslop-ko
/plugin install unslop-ko@unslop-ko
```

## 쓰는 법

글을 붙여 넣고 "AI 티 지워줘", "윤문해줘", "슬롭 지워줘"라고 한다.

500자 이하의 짧은 글은 주 에이전트가 직접 고치고 점검 에이전트만 부른다. 그보다 긴 글은 진단, 윤문, 점검을 차례로 거친다.

## 무엇을 고치나

문장 속 가운뎃점 나열, 줄표로 덧붙이기, 화살표, 괄호 보충, "라벨: 내용" 줄, 굵은 머리 문장의 반복, 대구와 "X가 아니라 Y", 따옴표와 낫표 강조, 번역투.

## 무엇을 두나

문서 머리 정보, 표 머리글, 보고 양식의 머리글, 명사로 끝나는 개조식 줄, 날짜와 버전 표기, 버튼 이름과 코드. 같은 종류의 문서를 사람이 써도 나오는 모양은 양식으로 본다. 비유와 경구도 고치지 않는다.

## 스크립트

```
python3 scripts/unslop_check.py count 원문.txt
python3 scripts/unslop_check.py compare 원문.txt 고친글.txt
```

파이썬 3만 있으면 돈다. 외부 라이브러리를 쓰지 않고, 파일을 만들거나 고치지 않고, 네트워크를 쓰지 않는다. compare는 숫자가 어긋나면 종료 코드 1, 바뀐 비율이 50%를 넘으면 2를 낸다.

## 넣은 글이 남는 곳

주 에이전트가 숫자를 대조하려고 원문과 고친 글을 작업 폴더에 파일로 저장한다. 스크립트는 파일을 남기지 않는다.

## 근거

AI로 만든 문서 14개, 35만 자에서 주제와 상관없이 따라붙는 습관을 세어 목록을 만들었다. 가운뎃점은 14개 모두에 나왔고 천 자에 14.4번이었다. 번역투는 35만 자에서 4번이었다.

## 빌린 것

뜻 잠금은 [humanizer-kr](https://github.com/hjongc/humanizer-kr), 밀도 기준은 [humanizer-ko](https://github.com/IsaacEryn/humanizer-ko), 진단과 윤문과 점검을 나누는 구성과 코드로 하는 대조는 [im-not-ai](https://github.com/epoko77-ai/im-not-ai)에서 생각을 빌렸다. 문장을 옮겨 오지는 않았다.

## 하지 않는 것

AI 탐지기를 통과시키는 용도로는 쓰지 않는다. 사실을 확인하지 않는다.
